# Preview CMS contenu

Cette branche étend le CMS sans modifier la production avant validation.

- `/admin` : CMS existant (actualités, paramètres, médias)
- `/admin-contenu` : hero d'accueil, vidéos/posters et cartes Maternelle/Primaire/Collège/Lycée
- fallback automatique vers le contenu versionné si aucune valeur CMS n'est enregistrée
